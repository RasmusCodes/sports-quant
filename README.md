# sports-quant: probability models vs betting markets (NBA, NFL)

A research platform that estimates game probabilities, compares them with margin-free market
prices, and tests whether systematic mispricing exists. **The goal is to measure market
efficiency, not to promise profitable betting.** Every number in the paper is regenerated by the
scripts below from dated raw files.

**Project page:** [rasmuscodes.github.io/projects/sports-quant](https://rasmuscodes.github.io/projects/sports-quant/)

Headline result (details in `paper/paper.md`): over 14,338 out-of-sample NBA games the best
model (an ensemble) improves on Elo by 0.016 log loss, yet on the 1,556 games priced by Kalshi
it is 0.016 *worse* than the closing price, and the closing price encompasses every model
(adding the model to the price does not improve forecasts). The NFL tells the same story against
sportsbook closing lines (3,685 games). Day-ahead prices do drift toward the model (bets 24 hours
out beat the close by about 1 point), but by less than Kalshi's taker fee; NBA spreads and totals show no
edge after execution costs. An apparent player-props signal passed a pre-registered replication on 728
held-out games, but it came from scoring props on players who sat out as losses: Kalshi settles those at a
pre-game fair price. Scored the way the markets settle, the player model adds nothing (weight 0.02, SE 0.05)
and every prop trading rule loses money.

## What is in this repository

Code, tests, the paper (`paper/paper.md`, also as a standalone `paper/paper.html`), the props
pre-registration, and the aggregate results the paper is built from (`outputs/**/*.csv`, `*.json`,
figures). Not included: the downloaded data (`data/`: raw API responses, tidy tables, the SQLite odds
database), row-level panels (`*.parquet`) and the dashboard (`dashboard/index.html`). They are left out
because of size and because they would republish the exchanges' price data; the commands below rebuild
them from the public sources listed in `DATA_SOURCES.md`. `outputs/nba/registered/MANIFEST.sha256`
records the hashes of the registered props files, including the panels that are not committed.

## Layout

```
sq/                      the library
  io/                    polite cached HTTP + one module per source (opendata, kalshi, polymarket, live, manual)
  data/                  tidy, timestamped NBA / NFL tables
  db/                    SQLite historical odds database (data/db/sports.sqlite)
  markets/               odds conversion, overround, five devig methods, Kalshi fee model, venue quotes
  models/                Elo, Glicko-2, Poisson, Bayesian state-space (Kalman), walk-forward logistic /
                         LightGBM / margin-adjusted models, Monte Carlo game simulation, tuning
  features/              schedule / rest / travel, NBA player availability, NFL starting-QB value
  eval/                  proper scoring rules, calibration, paired tests, encompassing, multiple testing
  backtest/              event-driven bankroll simulation: fractional Kelly, caps, fees, liquidity, CLV
  research/              pipelines, studies, figures, dashboard data
scripts/                 entry points (below)
tests/                   unit + information-leakage tests
data/raw, data/tidy      cache (with _manifest.jsonl) and parquet tables (not committed)
outputs/                 result tables, figures, logs
outputs/nba/registered/  frozen record of the pre-registered props study (written only by run_props_replication.py)
dashboard/index.html     self-contained dashboard, built by scripts/build_dashboard.py (not committed)
paper/                   research paper (Markdown + HTML)
```

Fetches are cached: re-running only downloads what is new (the current season's files and new
exchange listings). Hyperparameters are cached in `outputs/<league>/params.json`; pass
`--retune` to refit them. A full rebuild from an empty cache takes roughly 2-3 hours, mostly
exchange candle downloads at a polite request rate.

## Information-leakage controls

* Online models run predict-then-update by calendar day: all games on a date are predicted before
  any result from that date is used (`sq/models/base.py`).
* Hyperparameters of rating models are fitted on 2004-2015 (NBA) / 2002-2012 (NFL) only; ML models
  are walk-forward by season with inner validation on the last training season.
* Injury information is used only if the report was published before the decision time; three
  information sets (T-5m, T-6h, T-24h) are kept and each backtest decision time uses the matching one.
* Backtests trade the ask available at the decision time, never a mid or a later price.
* `tests/test_leakage.py` perturbs future results, same-day results, test-season outcomes, late
  injury reports and closing prices, and checks no earlier decision changes.

## Library quick reference

```python
from sq.markets import devig, odds
devig.two_way(odds.american_to_prob(-150), odds.american_to_prob(130), "shin")

from sq.models.base import run_online
from sq.models.kalman import KalmanScores
preds = run_online(KalmanScores.preset("nba"), games)          # p_home, mu_margin, sd_margin, mu_total ...

from sq.models.simulate import simulate_nba, price_from_sims
price_from_sims(simulate_nba(116, 110), spread=-5.5, total=226.5)

from sq.backtest.engine import Config, run
ledger, daily, summary = run(bets, Config(kelly_fraction=0.25, min_edge=0.02))
```
